# 캐릭터 그림 — ChatGPT 프롬프트

## 진행 순서
1. ChatGPT에서 새 대화를 열고 아래 「① 화풍 기준」 프롬프트를 넣는다. 마음에 들 때까지 다시 뽑는다.
2. 고른 그림을 `0_화풍기준` 폴더에 `style_anchor.png`로 저장한다.
3. 같은 대화에서 캐릭터를 하나씩 만든다. 각 캐릭터마다:
   - 「② 캐릭터 프롬프트」 = [공통 문구] + [캐릭터 설명]을 넣어 기본 표정 그림을 받는다.
   - 마음에 들면 「③ 표정 바꾸기」 문장 3개로 같은 그림의 표정만 바꾼다.
4. 대화가 길어져 화풍이 흔들리면, 새 대화를 열고 `style_anchor.png`를 첨부한 뒤 이렇게 시작한다: 「이 그림과 똑같은 화풍으로 그려 줘」.
5. 파일 이름은 아래 표대로 붙여서 해당 폴더에 올린다. 올렸다고 말해 주면 Claude가 배경 지우기, 크기 맞추기, 게임 적용, 테스트까지 한다.

**우선순위**: 1차 = 화풍 기준 + 손님 7종(28장). 게임에 넣어 확인한 뒤 2차(단골 8명) → 3차(직원, 불청객).

**저장 위치**: 구글 드라이브 「흥정왕 전당포 › 02_아트 › 캐릭터_원본」
| 폴더 | 내용 |
|---|---|
| 0_화풍기준 | style_anchor.png |
| 1_손님 | 손님 7종 × 표정 4 |
| 2_단골 | 단골 8명 × 표정 4 |
| 3_직원 | 직원 6명 × 기본 1장 |
| 4_불청객 | 불청객 10종 × 기본 1장 |

**파일 이름**: `영문키_표정.png`
- 표정: `ok`(보통), `happy`(기쁨), `angry`(화남), `meh`(시큰둥)
- 예: `seonbi_ok.png`, `seonbi_happy.png`

**주의**: 출시할 게임에 쓰려면 ChatGPT 이용약관의 상업적 이용 조건을 확인한다. 실존 게임, 만화, 연예인과 닮게 해 달라는 말은 넣지 않는다.

## ① 화풍 기준 (처음 한 번)

```
모바일 게임용 캐릭터 일러스트를 그려 줘. 이 그림이 앞으로 만들 캐릭터 30여 명의 화풍 기준이 될 거야.

[세계관] 우주 궤도에 떠 있는 조선 한옥 전당포. 동양풍 우주, 마법 물건 감정, 코미디 톤.
[화풍] 한국 민화와 수묵화 느낌의 2D 일러스트. 굵기가 변하는 먹 붓선 외곽선, 맑은 수채 채색, 은은한 한지 질감. 귀엽지만 유치하지 않은 코믹한 과장 체형(4등신 정도, 머리가 크고 표정이 잘 보이게). 색은 채도를 조금 낮춘 전통 오방색 계열. 우주 느낌은 소품으로만 살짝 준다(별 모양 장식, 은하 무늬 옷감, 작은 안테나나 헬멧 같은 것).
[캐릭터] 갓을 쓰고 흰 도포를 입은 젊은 선비. 한 손에 부채, 허리에 별 모양 노리개. 살짝 거만하지만 미워할 수 없는 표정.
[구도] 정면에서 약간 비스듬한 전신, 똑바로 서 있는 자세, 팔은 몸 옆이나 앞쪽(화면 밖으로 나가지 않게). 머리 위와 발 아래에 여백을 조금 둔다.
[형식] 세로 2:3, 투명 배경 PNG, 배경 그림 없음, 그림자 없음, 글자와 테두리 없음.
```

## ③ 표정 바꾸기 (손님·단골만, 기본 그림을 받은 뒤 같은 대화에서)
옷, 포즈, 크기, 화풍은 그대로 두고 얼굴만 바꾼다. 한 번에 하나씩 요청한다.
- `_happy`: 「방금 그림과 완전히 같은 캐릭터, 같은 포즈로 표정만 활짝 웃는 기쁜 표정으로 바꿔 줘. 투명 배경 유지.」
- `_angry`: 「방금 그 캐릭터의 기본 그림에서 표정만 화난 얼굴로 바꿔 줘. 눈썹 치켜올리고 얼굴이 붉게 달아오른 모습. 포즈·옷·크기는 그대로, 투명 배경 유지.」
- `_meh`: 「같은 기본 그림에서 표정만 시큰둥하게 바꿔 줘. 반쯤 감은 눈, 입을 삐죽. 나머지는 그대로, 투명 배경 유지.」

포즈나 옷이 바뀌어 나오면 「포즈와 옷은 기본 그림과 똑같이, 얼굴만」이라고 다시 요청한다.
