# 계산대 소품 — ChatGPT 프롬프트

캐릭터·물건을 만들었던 ChatGPT 대화에 붙여 넣는다. 결과 `props.png`를 드라이브 「02_아트 › 물건·배경_원본」에 올린다.

```
앞에서 만든 그림들과 똑같은 화풍(먹 붓선 외곽선, 맑은 수채 채색, 은은한 한지 질감)으로 게임 소품 시트 한 장을 그려 줘.
정사각형 1:1 이미지 한 장을 같은 크기의 2x2 칸으로 나누고, 칸마다 소품 하나를 정면에서 살짝 위로 내려다본 시점으로 칸의 75% 크기로 그려 줘. 칸 사이 넉넉한 여백, 칸끼리 겹치지 않게. 투명 배경 PNG, 칸 테두리·바닥 그림자·글자 없음.

왼쪽 위: 반닫이 궤짝 — 짙은 나무 궤짝, 놋쇠 모서리 장식과 둥근 자물쇠, 뚜껑이 닫힌 상태, 가로로 긴 모양.
오른쪽 위: 장부 더미 — 실로 묶은 옛 장부 세 권이 비스듬히 쌓여 있고 위에 붓 한 자루가 놓임. 가로로 긴 모양.
왼쪽 아래: 비단 방석 — 물건을 올려놓는 납작하고 넓은 타원형 방석, 네 귀퉁이에 술 장식. 색은 아주 밝은 미색(흰색에 가깝게, 나중에 게임에서 색을 입힘). 가로로 긴 모양.
오른쪽 아래: 도장 — 나무 손잡이가 달린 큰 인장, 아랫면에 붉은 인주가 묻어 있음. 세로로 선 모양.
```
