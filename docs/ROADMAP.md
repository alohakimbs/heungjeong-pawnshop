# 흥정왕 전당포 — 개발 로드맵

목표: 딜러스라이프2의 게임 시스템을 재현한 뒤 독자 콘텐츠로 발전시켜 구글 플레이에 출시한다.
엔진: Godot 4.7 (GDScript) · 저장소: GitHub(코드·빌드) + 구글 드라이브(기획·아트·빌드 결과물)
작업 방식: Claude가 매일 1회 예약 작업으로 개선 → 변경 내역(CHANGELOG) 기록 → 테스트 통과 시 반영.

## 원칙
- 규칙·구조는 원작을 따르되 이름·그림·대사·캐릭터는 전부 자체 제작 (스토어 심사·저작권 대비).
- 게임 로직은 화면과 분리해 헤드리스 테스트로 검증한다. 테스트가 깨지면 반영하지 않는다.
- 데이터(물건·손님·이벤트)는 JSON으로 관리해 코드 수정 없이 콘텐츠를 늘린다.
