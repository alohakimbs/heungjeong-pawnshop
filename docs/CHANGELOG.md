# 변경 내역

## 1.0.3 — 2026-11-22 (UI 어색한 곳 정리)
- 손님 그림을 원본 해상도로 다시 잘라 넣고 표시 크기를 줄여 선명하게. 비율 유지, 머리가 말풍선에 가리지 않게.
- 말풍선 한지 질감, 긴 대사에 맞춰 높이 증가.
- 계산대 앞판을 줄이고 꽃 장식 제거(빈 공간 → 손님·장부에).
- 창고·장부 글씨를 궤짝·책 위 한지 꼬리표로.
- 줄 선 손님은 뒤쪽에 작고 흐리게.
- 도장은 가운데 하나(제안, 낮은 채도 인주색)로, 최종 제안·거절은 책상 위 글씨로.
- 손님 부른 값을 누르면 바로 수락. 수락 문구 "그 값에 사겠소/팔겠소".
- 인내심을 향로·향·연기로 표시. −/+를 획으로 그려 크기 맞춤. 끌기 안내는 처음 3번만.
- 안내 쪽지를 손님 얼굴이 아닌 장부 위로.

## 1.0.2 — 2026-11-22 (방문객 정비·확장)
- 버그 수정: 아침 방문객(불청객)이 화면에 그려지지 않던 문제(방문 단계에서 캐릭터를 숨기고 있었음). 방문객에게 「成·破」 도장이 찍히던 것도 없앰. 이름표를 「방문객 · 이름」으로.
- 방문객 결과를 코드에서 `events.json`의 `res`(선택지별 갈래: 직원·창고·확률 조건, 돈·평판·손님 수·경험치·물건 효과)로 옮김. 코드 수정 없이 방문객을 늘릴 수 있음.
- 남아 있던 원작 시절 문구 정리: 「$900」「$200」 같은 달러 표기, 커피·유리창·리뷰 등 현대 배경 대사를 동양풍 우주 배경에 맞게 고침. 「경비원 마동」→「문지기」.
- 새 방문객 7종(10 → 17): 과거 보러 가는 선비(노잣돈), 달떡집 아낙(떡 돌리기), 구미호 방물장수(정체 모를 보따리 구입 — 가짜일 수도), 도깨비 땜장이(창고 물건 상태 한 단계 수리), 전단 돌리는 도령, 은하 도량형 검사관(시세꾼이 있으면 통과), 약초 할멈(경험치). 그림은 기존 손님 그림을 빌려 씀.
- 테스트 78개(방문객 효과 8개·화면 표시 1개 추가).
