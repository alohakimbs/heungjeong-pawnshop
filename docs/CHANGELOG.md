# 변경 내역

## 0.4.0 — 2026-11-21
- 게임 전체 로직을 Godot로 이식 (`scripts/core/game_state.gd`): 물건 생성·감정·가품, 손님 생성(성향·유형·단골 8명과 지난 거래 기억), 흥정·수락·거절·가품 지적, 창고(정밀 감정·수리·도매 처분), 직원 6종, 스킬 4종, 레벨, 가게 이전, 아침 신문·시세, 불청객 이벤트 5종, 경매, 마감 정산(임대료·급여·수리·도둑·가품 신고), 저장/불러오기.
- 대사·이벤트·손님 유형을 JSON으로 분리 (`lines.json`, `events.json`, `archetypes.json`).
- 자동 플레이 봇 추가: 무작위 봇 5명×30일(규칙 위반 0건), 숙련 봇 8명×30일(파산 0, 중앙값 순자산 > 시작 자금). 테스트 33개 통과.
- 밸런스 조정 (자동 플레이 데이터 근거):
  - 너무 비싸게/싸게 부를 때 인내심 감소 완화 (12+70×차이 → 8+45×차이). 기존엔 사러 온 손님 889명 중 대부분이 2~3번 만에 떠나 판매액 < 매입액이었음.
  - 창고가 찰수록 사러 오는 손님 증가 (35% → 최대 75%).
  - 판매 손님 마지노선 0.72 → 0.66 (매입 마진 확대).
  - 차고 단계 손님 5 → 6명, 골목 가게 이전 비용 $15,000 → $10,000.
  - 모르고 판 가품은 벌금 대신 환불(평판 -3). 알고 판 가품(감정 확인·의심 표시)만 벌금 1.5배·평판 -8.
- 남은 과제: 숙련 플레이도 30일 내 가게 이전을 못 함 → 진행 속도 추가 조정 필요.
