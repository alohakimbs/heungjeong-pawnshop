# 세계관 — 봉래 성계 (v3)

**기준 문서는 `docs/WORLD_HANDOFF.md`(사용자 제공, 2026-11-22)다.** 이 파일은 그 기준 위에 게임에 필요한 것을 「게임 제안」으로 덧붙인다. 충돌하면 기준 문서가 이긴다.
기준 그림: `docs/art/ref/unkyeong_city.png`(운경 전경), UI 기준: `docs/art/ref/ui_mock_haggle.png`.

## 1. 기준 문서의 현재 시안 (그대로 따름)
- 봉래 성계, 수도 **운경**: 산수화 같은 산악 지형에 층층이 자란 교역 도시. 수로·교량, 계단식 건물과 정원, 산을 따라 솟은 옥빛 에너지 시설, 부상열차, 공중 화물선, 짐꾼 로봇, 먼 산 사이의 거대한 원형 교역 시설.
- 옥 기반 에너지, 기술은 이동·장사·운송·도시 운영에 쓰인다.
- 화풍: 먹 붓선, 수채, 한지 질감(인물은 수묵 담채 반실사 기준 시트).
- 피할 것: 네온·과한 홀로그램·발광 문양, 특정 국가 복식/국가 상징 복제, 와칸다·비브라늄 등 기존 작품 복제, 플라스틱 3D 질감, 배경 원화 속 UI·가짜 글자.

## 2. 기준 문서의 「확장 제안」을 게임에서 쓰는 방식
- 「성옥」 이름, 등급·가공 품질에 따른 출력 차이, 위조품, 과열·정비 — **게임의 감정·흥정·가품 규칙과 이야기의 갈등으로 사용**. 확정 설정이 아니라 게임 안 해석임.
- 상단의 물류 운영과 운임 — 이야기의 맞수(흑운 상단)의 배경으로 사용. 상단의 **정치적 권한은 정하지 않음**.

## 3. 게임 제안 (사용자 확인 필요)
| 항목 | 게임에서 쓰는 내용 | 기준 문서와의 관계 |
|---|---|---|
| 주인공 | 할아버지 백운의 간판을 물려받은 전당포 주인. 수로 아래 좌판 → 산 중턱 운경 대전당 | 기준 문서 「주인공 미정」을 게임용으로 채움 |
| 가게 단계 | 수로 아래 좌판 → 다리목 전당 → 상단 거리 전당포 → 산 중턱 회랑 전당 → 운경 대전당 | 운경의 높이 구조(아래=시장, 중턱=공공)를 따름 |
| 인물 | 백운(=청운 도사), 묵향(흑운 상단 대행수, 옛 제자), 홍란(구미호족 상인), 왕 학사, 최 부인 등 | 묵향·홍란·백운은 사용자 기준 시트 있음 |
| 이야기 갈등 | 가짜 옥 부품 사고 → 감정을 한 상단이 독점할 것인가, 여럿이 함께 볼 것인가 | 성옥 품질·위조 확장 제안에서 출발. 정치체제는 다루지 않음 |
| 결말 | 운경 상인 회합에서 「공동 감정소」 또는 「장터의 맞수」 | 상인끼리의 모임일 뿐, 통치 기구가 아님 |
| 원형 교역 시설 | 게임 글에서는 「고리 교역항」으로 부름. 이동 방식은 언급하지 않음 | 이름만 붙임 |
| 외계 종족 | 기존 게임의 토끼족·구미호족·뿔족·기계족·두꺼비족 등을 손님으로 유지 | 기준 문서 「종족 미정」 — 확정 아님 |

## 4. 폐기한 이전 설정 (v1·v2)
우주조선, 임진년, 결계, 천강석, 다섯 구역(청룡항·백호곡·주작궁·현무원·황룡성), 운해 개방 300년. 게임 데이터에서 모두 제거함.
