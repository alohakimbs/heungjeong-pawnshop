# 세계관 v2 — 봉래(蓬萊) 성계

> 한 줄: 하늘에서 떨어진 「성옥」을 따라 동방 각지의 학자·장인·도사들이 모여 운해 너머에 숨어 키운 미래 문명. 삼백 년 전 문을 열고 은하의 외계 종족과 장사한다.
> v1(우주조선)은 한 나라의 역사에 기대고 있어 폐기. 특정 국가가 아니라 동아시아가 함께 공유하는 신화·미감 위에 세운다.

## 1. 블랙 팬서에서 가져올 것
블랙 팬서(2018)는 전 세계 약 13.5억 달러를 벌었다(Box Office Mojo). 성공 요인 중 이 게임에 옮길 수 있는 것:

| 블랙 팬서 | 봉래에 적용 |
|---|---|
| 한 부족이 아니라 여러 아프리카 문화를 섞음. 의상 디자이너 루스 E. 카터는 마사이·은데벨레·힘바 등에서 가져오되 "기록물처럼" 재현하지 않고 앞으로 밀어냈다 | 한·중·일 어느 한 나라가 아니라 **공유 요소**(신선 섬 봉래, 사신, 월궁 토끼, 구미호, 학·용·봉황, 먹·한지·옻칠·옥·등롱)를 섞고 미래 기술로 변형. 실제 국가 의상을 그대로 그리지 않는다 |
| 출발 질문: "식민지가 되지 않았다면 아프리카는 어떤 모습일까?" | 출발 질문: "동방의 신화와 장인 정신이 그대로 우주 시대까지 이어졌다면?" |
| 아프로퓨처리즘 = SF·기술 + 고대 신화 | 전통이 곧 첨단: 성옥 회로를 먹으로 그리고, 비행선 돛은 한지, 장갑은 옻칠 |
| 신비 광물 비브라늄 + 숨겨진 첨단 왕국 + 개방과 고립의 갈등 | 성옥 + 운해 뒤에 숨은 봉래 + 「운해를 더 열 것인가」 논쟁(신문·손님 대사로) |
| 강 부족·광산 부족·국경 부족처럼 실제 문화에서 단서를 딴 분파 | 다섯 구역(사신 + 황룡): 청룡항·백호곡·주작궁·현무원·황룡성 |
| 각 지역 관객이 자기를 긍정적으로 보는 경험("부정적 고정관념을 깸") | 어떤 나라·민족도 악역이나 웃음거리로 쓰지 않는다. 웃음은 직업·상황·종족 성격에서 |
| 무엇보다 재미있는 블록버스터 | 게임성이 먼저. 세계관은 대사·신문·이름으로 가볍게 스며들게 |

## 2. 설정
- **성옥(星玉)**: 아득한 옛날 떨어진 별의 옥. 기(氣)를 담아 증폭한다. 동방 어디서나 귀하게 여긴 옥의 이미지를 빌림.
- **봉래**: 성옥을 따라 모인 사람들이 운해(구름바다) 너머에 세운 나라. 수천 년 동안 숨어서 기술을 키움.
- **운해 개방**: 삼백 년 전. 지금은 개방 300주년. 별냥(성옥이 든 엽전, 兩/両)은 은하 공용 화폐.
- **다섯 구역**
  - 청룡항(靑龍港): 비행선 항구, 교역·상인
  - 백호곡(白虎谷): 성옥 광산, 광부·무구
  - 주작궁(朱雀宮): 예인·장인, 악기·의복·공예
  - 현무원(玄武院): 학당·서고·천문대·의원
  - 황룡성(黃龍城): 중심 도시, 대전당
- **주인공**: 봉래 변두리 출신 전당포 주인. 할아버지의 간판과 5,000냥으로 운해 변두리 좌판에서 시작해 황룡성 대전당까지.
- **가게 단계**: 운해 변두리 좌판 → 현무원 골목 전당 → 청룡항 저잣거리 전당포 → 주작궁 누각 전당 → 황룡성 대전당

## 4. 피할 것 (전 세계 출시 기준)
- 실제 국가·왕조·전쟁·연호(임진년 등), 실존 인물
- 국기·국가 상징, 욱일 문양, 특정 국가를 연상시키는 방사형 문양
- 영토·역사 분쟁 소재, 음식·의복 "원조" 논쟁 소재
- 한 나라의 고유 의상을 그대로 그리거나 다른 나라 것으로 부르기 → 여러 나라 요소를 섞은 「봉래복」(여밈 깃 + 넓은 소매 + 허리띠 + 미래 소재)
- 한 나라 고유어 직함(진사·대감·다이묘 등) → 학사·선생·부인·대인처럼 일반 호칭

## 5. 현지화 메모
- 지명·종족은 한자 표기를 기준으로 각 언어 읽기 사용(蓬萊: 봉래 / Penglai / 蓬莱 Hōrai).
- 화폐 兩/両: 냥 / liang / 両(りょう).
- 손님 이름 목록은 언어별로 따로 둔다(한국어판은 한국식 이름, 일본어판은 일본식…).

## 6. 그림 방향 (다음 그림부터)
- 이미 만든 그림 중 한복·갓이 뚜렷한 캐릭터(학사·견습 비행사)는 당장 바꾸지 않는다. 다음 그림을 만들 때 봉래복 기준으로 하나씩 교체한다.
- 배경은 한옥만이 아니라 등롱·둥근 달문·누각·비행선 부두처럼 공통 요소 + 미래 기술(빛나는 성옥 회로, 떠 있는 정자).
