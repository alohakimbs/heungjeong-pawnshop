## 데이터 보안 (Data safety)
- 앱이 사용자 데이터를 수집하거나 공유하나요? → 아니요
- 데이터 암호화·삭제 요청: 수집 데이터 없음
- 근거: 게임은 인터넷 권한 없이 동작하고, 저장 파일(user://save.json)은 기기 안에만 있음

## 콘텐츠 등급 (IARC 설문) 예상 답변
- 폭력: 없음 (손님이 화를 내며 나가는 연출뿐)
- 성적 콘텐츠·노출: 없음
- 욕설·비속어: 없음 (대사 검수 필요 시 lines.json)
- 약물·음주·흡연: 없음 (물건 목록에 와인 잔 세트 — 음주 묘사 아님)
- 도박 또는 모의 도박: 없음 (복권 이벤트는 등급 영향 가능성 때문에 점쟁이 이벤트로 교체함)
- 사용자 간 소통·위치 공유·디지털 구매: 없음
- 예상 등급: 전체이용가 또는 3+ (최종 등급은 설문 결과로 결정)

## 대상 연령
- 13세 이상 권장 (흥정·경영 시뮬레이션). 아동 대상 앱으로 등록하지 않음.

## 광고 포함 여부
- 현재: 아니요 (수익 모델 결정 후 변경)
