# 이야기 「흥정왕의 간판」 — 3막 + 에필로그 (게임 제안)

세계관 기준: `docs/WORLD_HANDOFF.md`. 정치체제·관문 이동 방식·역사는 다루지 않는다.
장면 데이터: `godot/data/story.json` (아침에 조건이 맞으면 인물 그림과 함께 뜸).

## 인기 게임을 위해 넣은 장치
1. **첫 장면에 수수께끼**: 간판 뒤에 숨긴 「흥」 자 인장 — 끝까지 궁금하게.
2. **이유 있는 맞수**: 묵향은 악당이 아니라 "가짜 때문에 사람이 다친다"는 옳은 걱정을 잘못된 방법(독점)으로 풀려는 사람.
3. **반전 두 번**: 가짜는 할아버지의 기술로 만들어졌다(제자 중 누군가) / 청운 도사가 할아버지.
4. **선택이 뒤에서 돌아옴**: 「천문항의 꼬리표」에서 묵향에게 알리면 회합에서 묵향이 내 편, 증거만 모으면 회합에서 맞섬 → 결말 장면이 달라짐.
5. **고정 조연과 웃음**: 홍란(능글맞은 동업자 겸 맞수), 한탕(허둥대는 운반책), 왕 학사·최 부인(소문통).
6. **장소와 이야기 연결**: 월류시장(가짜 유통) · 옥맥공방(가짜 감정) · 천문항(밀반입 경로) · 설운관(항로 증거) — 가게 준비로 가는 곳이 이야기 무대.
7. **에필로그 떡밥**: 운경 밖에서 온 「흥」 자 그릇 → 다음 이야기(업데이트) 여지.
